# C.I. #3 — Agent Evidence Sufficiency Engine

Evaluate structured observations against an explicit evidence contract before proceeding in an agent workflow.

## Live tool

[Run on Apify](https://apify.com/bono718/agent-evidence-sufficiency-engine)

## What it does

One claim per call. Checks observation age, required source types, caller-declared independent groups, provenance-reference presence and supplied confidence thresholds. Compares normalized JSON values with the declared expected value. Returns SUPPORTED, CONTRADICTED or INSUFFICIENT with an audit trail.

Example: a delivery requires a carrier event and an independent receiver acknowledgement within 24 hours. Both supplied: SUPPORTED. Receiver missing: INSUFFICIENT. Conflicting eligible evidence: INSUFFICIENT by default.

## Boundaries

This v0.1 release supports exact JSON-value comparison. It does not interpret natural-language evidence, fetch observations, authenticate provenance, independently prove source independence or calibrate confidence. Confidence is the minimum supplied value on the decisive side, not a probability that a real-world claim is true. Other predicates and semantic evaluation are not available in this release.

## Input and output

See the Actor README for the full contract and runnable JSON example. Caller provides evaluation_time, evidence requirements and evidence records. Output includes eligible evidence IDs, reason codes, independent-source counts and freshness/provenance assessments.
