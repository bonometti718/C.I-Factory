# C.I. #01 — Citation Remediation Payload Generator

**Status:** LIVE · Apify

## Purpose

Transforms caller-supplied AI citation evidence and HTML snapshots into deterministic, machine-readable remediation instructions for a downstream HTML consumer.

It is designed for the specific case where supplied citation evidence references a competitor page but omits the target page, while relevant facts already exist in the target snapshot.

## Machine Contract

**Inputs:** target URL, competitor URL, query, supplied citation evidence, HTML snapshots, and grounded facts.

**Outputs:** versioned JSON containing diagnosis, snapshot hashes, proposed changes, preconditions, acceptance tests, provenance, and warnings.

Possible outcomes include `ready`, `no_gap`, and `no_action`.

## Supported Operations

- `append_html`
- `append_json_ld`
- typed acceptance tests: `selector_count`, `text_contains`, `json_ld_webpage_url`

The capability returns instructions. It does **not** directly edit a website.

## Example

```json
{
  "targetUrl": "https://example.com/product",
  "competitorUrl": "https://competitor.example/product",
  "query": "Does Acme export CSV?",
  "evidence": {
    "answer": "The competitor offers CSV exports.",
    "citedUrls": ["https://competitor.example/product"]
  },
  "facts": [{
    "text": "Acme exports reports in CSV format.",
    "sourceUrl": "https://example.com/product"
  }]
}
```

## Boundaries

No live page fetching, citation collection, ranking prediction, CMS writes, bulk processing, or arbitrary executable tests. Supplied evidence is not independently authenticated.
